# Fenbrix Salon Website Demo

Clickable frontend demo (React + Vite + Tailwind + Lucide). No backend; all data is mock data.

## Run
npm install
npm run dev

## Edit client details
Open `src/SalonDemo.jsx` and edit the blocks at the top:
- `SALON` — name, address, phone, WhatsApp, hours, home-service areas (currently DEMO data)
- `SERVICES`, `CATEGORIES` — services, prices, durations
- `GALLERY`, `REVIEWS` — portfolio images and sample reviews
- `PHOTOS` — swap the Unsplash placeholders for the salon's own photos
- `PROJECT`, `PRICING` — proposal figures shown in the "Proposal" view
